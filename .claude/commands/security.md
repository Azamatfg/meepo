# Security — аудит безопасности

Проведи аудит безопасности изменённого кода.

## OWASP Top 10
1. **Injection** — SQL инъекции (параметризованные запросы?), XSS
2. **Broken Auth** — токены, сессии, пароли в коде
3. **Sensitive Data** — API ключи, пароли, .env в git
4. **XXE/SSRF** — обработка XML, внешние запросы
5. **Broken Access Control** — проверки прав в хэндлерах
6. **Security Misconfig** — CORS, headers, debug mode
7. **XSS** — рендеринг пользовательских данных
8. **Insecure Deserialization** — JSON parsing
9. **Known Vulnerabilities** — устаревшие зависимости
10. **Logging** — не логируются ли пароли/токены

## Общие проверки
- Все SQL запросы параметризованы?
- Проверка прав на всех protected эндпоинтах?
- Мобилка: токены в secure storage, нет хардкоженных ключей?
- Фронт: API вызовы через авторизованный клиент?

## Отчёт
- 🔴 Критично (нужно фиксить сейчас)
- 🟡 Средне (планировать фикс)
- 🟢 Информационно (учесть на будущее)

Если нашёл критичное — исправь сразу.
