# Updates — проверка обновлений Anthropic и Claude Code

Проверь последние обновления от Anthropic и предложи улучшения для нашего рабочего процесса.

## Шаг 1: Собери информацию

Используй WebSearch и WebFetch чтобы проверить **все** эти источники:

1. **Claude Code changelog** — поищи `"Claude Code changelog 2026"` или `"Claude Code release notes"`
2. **Anthropic блог** — `site:anthropic.com/research` последние публикации
3. **Anthropic docs** — `site:docs.anthropic.com "what's new"` или `"claude code new features"`
4. **GitHub releases** — `site:github.com/anthropics/claude-code releases`
5. **Claude Code docs обновления** — `"claude code" new feature 2026`

## Шаг 2: Проанализируй

Для каждого найденного обновления определи:
- **Что нового**: фича, изменение, deprecation
- **Релевантность для нас**: высокая / средняя / низкая
- **Наш стек**: см. CLAUDE.md

## Шаг 3: Проверь наш текущий setup

1. Прочитай `.claude/settings.json` — текущие hooks
2. Прочитай `.claude/agents/` — текущие subagents
3. Прочитай `~/.claude/settings.json` — permissions и настройки
4. Прочитай `CLAUDE.md` — текущие правила

## Шаг 4: Отчёт

### Новое от Anthropic
- Список обновлений с датами и ссылками
- Фокус на то что можно применить

### Что можно улучшить у нас
- Новые hooks которые стали доступны
- Новые возможности agents/teams
- Новые MCP серверы или tools
- Изменения в API/SDK
- Deprecated фичи которые мы используем

### Конкретные действия
- Что добавить/изменить в hooks
- Что добавить/изменить в agents
- Что обновить в settings
- Что обновить в CLAUDE.md

### Что почитать
- Ссылки на статьи/доки которые стоит изучить

## Правила
- Только конкретные, применимые вещи — не общие рекомендации
- Если нашёл новую фичу — покажи пример использования
- Если фича уже настроена — не предлагай повторно
- Обнови memory если нашёл что-то важное для будущих сессий
- Язык: русский для текста, английский для кода
