# Sync — актуализация памяти и прогресса

Обнови memory проекта, чтобы следующая сессия начиналась с полным контекстом.

## Шаг 1: Сбор данных (параллельно)
1. `git log --oneline --since="7 days ago"`
2. `git diff --shortstat HEAD~10..HEAD`
3. Прочитай MEMORY.md и все memory-файлы проекта
4. `git log --oneline -1`

## Шаг 2: Проверка каждого memory-файла
- project_* — обнови прогресс, перенеси сделанное из «следующие» в «реализованные», пересортируй приоритеты
- feedback_*, reference_* — проверь, не устарели ли; добавь новый feedback пользователя из сессии

## Шаг 3: Обновление MEMORY.md
- Обнови описания изменённых файлов, все файлы указаны, без дублей

## Шаг 4: Отчёт
- Какие файлы обновлены и почему / какие актуальны
- Приоритеты на следующую сессию

## Правила
- НЕ создавай новые memory-файлы без причины, НЕ дублируй информацию
- Описания в MEMORY.md — до 100 символов
- Даты только абсолютные (2026-04-05)
- Актуальность проверяй через git log и код, не по памяти
