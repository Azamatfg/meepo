# Investigate — системная отладка бага

Структурированный подход к поиску и исправлению бага.

## Вход
Пользователь описывает баг: что происходит, что ожидается, где воспроизводится.

## Шаг 1: Воспроизведение
- Найди код, отвечающий за описанное поведение
- Прочитай релевантные файлы
- Сформулируй гипотезу: почему это происходит

## Шаг 2: Локализация
- Сужай область поиска: файл → функция → строка
- Проверь логи если доступны
- Проверь граничные случаи (null, пустые списки, таймауты)

## Шаг 3: Root Cause
- Определи корневую причину (не симптом)
- Объясни пользователю в 1-2 предложениях

## Шаг 4: Фикс
- Минимальное изменение для исправления
- Не трогай код который не связан с багом
- Проверь что фикс не ломает другое

## Шаг 5: Верификация
- Запусти анализ/сборку
- Если возможно — проверь в симуляторе

## Правила
- НЕ гадай — читай код
- НЕ рефактори "заодно"
- Если не уверен в причине — спроси у пользователя
- Заморозь скоуп: работай только над этим багом
