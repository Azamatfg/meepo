# Retro — ретроспектива сессии

Проведи ретроспективу текущей рабочей сессии.

## Анализ
1. Прочитай git log за сегодня: `git log --oneline --since="today"`
2. Посчитай: коммитов, файлов изменено, строк добавлено/удалено
3. Проверь memory файлы — актуальны ли?

## Отчёт

### Что сделано
- Список фич/фиксов (по коммитам)

### Что пошло хорошо
- Подходы которые сработали
- Инструменты которые помогли

### Что можно улучшить
- Где застряли и почему
- Что заняло дольше чем нужно
- Паттерны ошибок (повторяющиеся проблемы)

### Уроки
- Что запомнить для следующих сессий
- Сохранить в memory если что-то не очевидное

### Следующие шаги
- Что осталось сделать
- Приоритеты на следующую сессию

## Правила
- Будь честным, не приукрашивай
- Конкретика, не общие фразы
- Обнови memory файлы если нужно
